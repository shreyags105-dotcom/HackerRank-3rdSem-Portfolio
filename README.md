## Problem Overview

### 1. Diagonal Difference

Calculates the absolute difference between the sums of the primary and secondary diagonals of a square matrix.

**Complexity:**

* Time: O(N)
* Space: O(1)

### 2. Dynamic Array

Uses a collection of dynamic sequences and processes queries using the XOR operation to determine the appropriate sequence.

**Complexity:**

* Time: O(N + Q)
* Space: O(N)

### 3. Time Conversion

Converts a 12-hour AM/PM time format into 24-hour military time format.

**Complexity:**

* Time: O(1)
* Space: O(1)

### 4. Compare the Triplets

Compares the corresponding elements of two triplets and calculates the scores for each participant.

**Complexity:**

* Time: O(1)
* Space: O(1)

### 5. Sparse Arrays

Uses frequency mapping to efficiently count how many times each query string occurs in the given collection of strings.

**Complexity:**

* Time: O(N + Q)
* Space: O(N)
